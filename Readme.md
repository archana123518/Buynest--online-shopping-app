# BuyNest – Online Shopping Application

BuyNest is a Full Stack E-Commerce Web Application developed to provide users with a simple and convenient online shopping experience.

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- ASP.NET Core Web API
- C#

### Database
- PostgreSQL
- Entity Framework Core

## Features

- User Registration and Login
- Product Listing
- Product Categories
- Shopping Cart
- Order Management
- Payment Management
- Admin Product Management
- Search Products

## Project Structure

- `BuynestFrontend` – React frontend application
- `BuynestAPI` – ASP.NET Core Web API backend

## Developer

Developed as a Full Stack E-Commerce Project.
